# RVS-Seminarski

Uputstvo:
1.Za pokretanje rada prvo morate otvoriti fajl RESTORAN_baza.sql koji se nalazi u folderu 1_slojpodataka/baza podataka.ovaj fajl ce kreirati novu bazu podataka.
2.Proveriti bazu podataka-u fajlu WEB.conf unutar solutiona promeniti konekciju sa vasom bazom podataka.Alternativa(mnogo brzi nacin) u visual studio pritisnite view u gornjem meniju,zatim na server explorer i u prozoru za baze podatak dodate vasu bazu podataka.
3.RESTORE NuGet Packages.
4.SETUP MILTIPLE START UP PROJECT-Na solution kliknete na proporties i pod opcijom startap porject stavite korisnicki interface i web servise kao start.
5.Kad ste pokrenuli projekat mozete se ulogovati kao jedan od dva korisnika:admin / 1234 i user / 1234
6.Uzivajte😀
